내 금융 데이터는 오직 내 손안에, 독립형 스마트 가계부

금융 푸시 알림과 문자를 감지하여 개발사 서버 전송 없이 100% 스마트폰 내부에서만 안전하게 가계부를 자동 정리합니다. 사용자의 개인 Google Drive를 통한 프라이빗 백업만을 지원합니다.

📱 100% 온디바이스 처리: 금융 거래 내역이 외부 서버로 일체 전송되지 않습니다.
☁️ 프라이빗 Google Drive 백업: 사용자 본인의 개인 계정 드라이브에만 암호화 보관됩니다.
⚡ 자동 카테고리 분류: 입출금 알림을 감지하여 지출 유형을 스마트하게 정리합니다.

SSH++

Mobile SSH Client

안전하고 스마트한 모바일 원격 서버 관리의 새로운 기준

모바일 환경에서 리눅스 원격 서버를 안전하게 접속하고 관리하는 클라이언트입니다. Zero-Telemetry 원칙과 안드로이드 Keystore 하드웨어 암호화, AI 터미널 가드레일을 제공합니다.

🔐 Keystore 하드웨어 암호화: SSH 개인키와 비밀번호가 보안 칩셋에 철저히 격리됩니다.
🤖 AI 터미널 가드레일: 위험 명령어(rm -rf 등)를 실시간 감지하여 모바일 오입력을 방지합니다.
🚫 Zero-Telemetry 보장: 터미널 세션, 호스트 주소, 입력 명령어를 절대 수집하지 않습니다.

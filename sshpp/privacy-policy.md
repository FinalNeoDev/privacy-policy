## 1. 기본 원칙 (Zero-Telemetry & Local-First)

- **SSH++는 이용자의 원격 서버 접속 정보, 인증 자격증명(비밀번호/개인키), 터미널 입출력 텍스트를 개발사나 개발자가 운영하는 별도의 중앙 서버로 일체 전송하거나 수집·저장하지 않습니다.**
- 본 앱은 이용자의 스마트폰 단말기(Local Device) 내부에서만 독립적으로 동작하는 **온디바이스(On-Device) 로컬 퍼스트(Local-First)** 원격 인프라 관리 도구입니다.
- 본 앱은 사용자의 기기 식별값(ADID/IMEI)이나 행태 패턴을 추적하는 **제3자 상용 광고 SDK(AdMob 등), 사용자 행태 추적기(Tracker), 서드파티 분석 툴(Google Analytics, Firebase, Sentry 등)을 일체 탑재하지 않은 100% 무광고·무추적(Zero-Telemetry) 소프트웨어**입니다.

앱은 원격 SSH 터미널 접속 및 AI 보조 기능 제공을 위해 기기 내에서 다음과 같은 최소한의 데이터를 처리합니다.

| 구분 | 처리 항목 | 처리 및 저장 방식 | 처리 목적 | 저장 및 전송 위치 |
| :--- | :--- | :--- | :--- | :--- |
| **서버 접속 프로필** | 호스트 주소(IP/도메인), 포트 번호, 사용자명, OS 유형, 별칭, 메모, 태그 | 로컬 SQLite 데이터베이스 (`ssh_plus.db`) | 원격 SSH 서버 목록 관리 및 세션 연결 | **사용자 기기 내부(로컬)** 에만 저장<br>(개발자 서버 전송 일체 없음) |

| **AI API 키 (선택)** | Google, OpenAI, Anthropic, DeepSeek, xAI 등의 BYOK API Key | **Android Keystore 기반 암호화 보관** | 사용자 본인 계정의 LLM 모델 직접 호출 | **사용자 기기 보안 볼트**에만 보관<br>(해당 AI 제공사로만 직접 전송) |
| **터미널 개인화 설정** | 폰트 패밀리, 글자 크기, 커스텀 색상 테마, 블루투스 키보드 모드, 언어 설정 | 로컬 SharedPreferences 및 SQLite | 사용자 맞춤형 터미널 뷰 제공 | **사용자 기기 내부(로컬)** 에만 저장 |

## 3. 네트워크 통신 및 제3자 데이터 전송 안내

SSH++는 어떠한 경우에도 개발자의 프록시 서버나 중계 서버를 경유하지 않으며, 모든 네트워크 연결은 **사용자 기기에서 목적지 서버로 100% 직접(Direct P2P)** 연결됩니다.

### 1) SSH 원격 접속 통신
- 이용자가 등록한 원격 서버와의 통신은 표준 SSH 프로토콜(포트 22 또는 사용자 지정 포트)을 통해 단말기와 원격 서버 간에만 종단간 암호화(End-to-End Encryption) 상태로 직접 이루어집니다.
- 개발자는 통신 패킷, 터미널 세션 내용, 파일 전송 데이터를 절대 중계하거나 모니터링할 수 없습니다.

### 2) AI 어시스턴트 BYOK (Bring Your Own Key) 다이렉트 통신
- 사용자가 직접 AI 어시스턴트 기능을 활성화하고 본인의 API Key를 등록한 경우에 한해 통신이 발생합니다.
- **다이렉트 통신**: 제3자 중계 서버 없이 사용자 기기에서 각 AI 공식 엔드포인트(Google Gemini API, OpenAI API, Anthropic API 등)로 직접 전송됩니다.
- **민감정보 마스킹 (Sanitizer)**: 터미널 버퍼 내용을 AI 프롬프트로 전송하기 직전, 단말기 내부에서 공인 IPv4 주소, API 키, 패스워드, JWT 토큰 패턴을 자동 감지하여 `[REDACTED_IP]`, `[REDACTED_KEY]`로 사전에 마스킹 처리하여 프라이버시를 보호합니다.
- 사내망/폐쇄망 환경을 위해 로컬 Ollama 모델 호출 시 외부 인터넷 연결 없이 사내 로컬 호스트(`http://localhost:11434` 등)와만 다이렉트 통신합니다.

## 4. 개인정보의 보관 및 파기 절차

1. **로컬 데이터의 보관**:
   - 모든 호스트 프로필, 암호화된 비밀번호/개인키, 스니펫, 폰트 및 테마 설정은 사용자의 스마트폰 샌드박스 내부 격리 영역에만 보관됩니다.
2. **영구 파기**:
   - 사용자가 호스트 또는 스니펫을 삭제하면 즉시 로컬 데이터베이스에서 물리적으로 삭제됩니다.
   - 사용자가 스마트폰에서 **앱을 삭제(언인스톨)** 하거나 안드로이드 설정에서 **'데이터 삭제'**를 실행하는 즉시, Android Keystore 암호화 키와 함께 기기 내 저장된 모든 데이터는 영구 파기되어 어떠한 방법으로도 복구할 수 없습니다.

## 5. 앱 접근 권한 안내

SSH++는 원격 터미널 통신 및 글꼴 불러오기를 위해 최소한의 권한만을 요청하며, 불필요한 위치, 연락처, 마이크, 카메라 등의 권한은 일체 요구하지 않습니다.

1. **인터넷 통신 (`android.permission.INTERNET` - 필수)**:
   - 사용자가 지정한 원격 SSH 서버와의 보안 쉘 접속 및 사용자가 요청한 BYOK AI API 다이렉트 호출을 위해 사용됩니다.
2. **네트워크 상태 확인 (`android.permission.ACCESS_NETWORK_STATE` - 필수)**:
   - 세션 연결 전 Wi-Fi/모바일 데이터 활성화 여부를 사전에 확인하여 불필요한 연결 실패 및 소켓 에러를 방지합니다.

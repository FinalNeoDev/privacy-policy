SSH++ 개인정보처리방침

시행일자: 2026년 10월 27일 (최종 갱신일: 2026년 11월 10일)

FINALNEO(개발자: FinalNeoDev, 이하 "개발사 및 개발자")는 정보주체의 자유와 권리 보호를 위해 「개인정보 보호법」 및 관계 법령, Google Play 개발자 배포 정책 및 사용자 데이터 정책(User Data Policy)을 엄격히 준수합니다. 'SSH++ (Mobile SSH Client & AI DevOps Assistant)'(이하 "앱" 또는 "서비스") 이용자의 개인정보 및 중요 자격증명을 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보처리방침을 수립·공개합니다.

1. 기본 원칙 (Local-First & On-Device Security)

  • SSH++는 이용자의 원격 서버 접속 정보, 인증 자격증명(비밀번호/개인키), 터미널 입출력 텍스트를 개발사나 개발자가 운영하는 별도의 중앙 수집 서버로 일체 전송하거나 저장하지 않습니다.
  • 본 앱은 이용자의 스마트폰 단말기(Local Device) 내부에서만 독립적으로 동작하는 온디바이스(On-Device) 로컬 퍼스트(Local-First) 원격 인프라 관리 도구입니다.
  • 본 앱은 무료 서비스 운영을 위해 서버 목록 화면 하단에 한하여 Google AdMob 배너 광고를 게재합니다. 광고 SDK는 Google Play 정책에 따라 기기 광고 식별자(AD_ID)를 사용할 수 있으나, SSH 접속 정보, 개인키, 비밀번호, SFTP 파일 및 터미널 세션 데이터는 광고 SDK를 포함한 어떠한 외부 서버와도 절대 공유되지 않으며 100% 기기 내부에만 격리 보관됩니다.

2. 처리하는 데이터 항목 및 처리 목적

앱은 원격 SSH 터미널 접속 및 AI 보조 기능 제공을 위해 기기 내에서 다음과 같은 최소한의 데이터를 처리합니다.

서버 접속 프로필 호스트 주소(IP/도메인), 포트 번호, 사용자명, OS 유형, 별칭, 메모, 태그 로컬 SQLite 데이터베이스 (ssh_plus.db) 원격 SSH 서버 목록 관리 및 세션 연결 사용자 기기 내부(로컬) 에만 저장
(개발자 서버 전송 일체 없음)

단축 명령어 (스니펫) 명령어 템플릿, 동적 변수, OS 타깃, 실행 확인 플래그, 카테고리 로컬 SQLite (command_snippets) 반복 명령어 빠른 실행 및 동적 변수 치환 사용자 기기 내부(로컬)에만 저장

3. 네트워크 통신 및 제3자 데이터 전송 안내

SSH++는 어떠한 경우에도 개발자의 프록시 서버나 중계 서버를 경유하지 않으며, 모든 네트워크 연결은 사용자 기기에서 목적지 서버로 100% 직접(Direct P2P) 연결됩니다.

🔒 SSH 원격 접속 통신

이용자가 등록한 원격 서버와의 통신은 표준 SSH 프로토콜을 통해 단말기와 원격 서버 간에만 종단간 암호화(End-to-End Encryption) 상태로 직접 이루어집니다. 개발자는 통신 패킷 및 터미널 내용을 절대 모니터링할 수 없습니다.

🤖 AI 어시스턴트 BYOK 다이렉트 통신

제3자 중계 서버 없이 각 AI 공식 엔드포인트로 직접 전송됩니다. 프롬프트 전송 전 내부 마스킹 필터(Sanitizer)가 IP, API 키, 패스워드를 [REDACTED] 처리하여 전송합니다.

4. 데이터의 보관 및 영구 파기 절차

  • 로컬 데이터의 보관: 모든 호스트 프로필, 암호화된 비밀번호/개인키, 스니펫, 폰트 및 테마 설정은 사용자의 스마트폰 샌드박스 내부 격리 영역에만 보관됩니다.
  • 영구 파기: 사용자가 호스트 또는 스니펫을 삭제하면 즉시 로컬 데이터베이스에서 물리적으로 영구 삭제됩니다.
  • 앱 삭제 시 즉시 파기: 사용자가 스마트폰에서 앱을 삭제(언인스톨)하거나 안드로이드 설정에서 '데이터 삭제'를 실행하는 즉시, Android Keystore 암호화 키와 함께 기기 내 저장된 모든 데이터는 영구 파기되어 어떠한 방법으로도 복구할 수 없습니다.

5. 앱 접근 권한 안내

SSH++는 핵심 서비스 제공을 위해 최소한의 권한만을 요청하며, 불필요한 위치, 연락처, 마이크, 카메라 등의 권한은 일체 요구하지 않습니다.

  • 인터넷 통신 (android.permission.INTERNET - 필수): 사용자가 지정한 원격 SSH/SFTP 서버와의 보안 쉘 접속, BYOK AI API 직접 호출 및 서버 목록 하단 배너 광고 로드를 위해 사용됩니다.
  • 네트워크 상태 확인 (android.permission.ACCESS_NETWORK_STATE - 필수): 연결 전 Wi-Fi/모바일 데이터 활성화 여부를 사전에 확인하여 불필요한 소켓 오류를 방지합니다.
  • 생체인증 및 광고 식별자 (USE_BIOMETRIC / com.google.android.gms.permission.AD_ID): 생체인증 권한은 앱 잠금 해제 시 기기 로컬 인증에만 사용되며, 광고 식별자(AD_ID) 권한은 서버 목록 화면 하단의 Google AdMob 배너 광고 표출 및 Google Play 정책 준수를 위해 사용됩니다.
